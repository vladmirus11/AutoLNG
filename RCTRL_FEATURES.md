# Функционал правого Ctrl (Right Ctrl)

## Описание

Добавлена возможность ручного переключения раскладки для последнего набранного слова или строки с помощью клавиши **Правый Ctrl**.

## Принцип работы

### Одиночное нажатие правого Ctrl
- Переключает **последнее набранное слово** туда-сюда (русский ↔ английский)
- Использует сохранённую копию буфера клавишных событий для корректного переключения
- Определяет текущую активную раскладку и переключает на альтернативную

### Двойное нажатие правого Ctrl
- Интервал между нажатиями: **300 мс**
- Переключает **раскладку клавиатуры** в активном окне на противоположную
- Русская → Английская
- Английская → Русская

## Технические детали

### Хранение состояния
В класс `TAutoCorrectEngine` добавлены поля:
- `FRightCtrlPressTime: Cardinal` - время последнего нажатия
- `FRightCtrlPressCount: Integer` - счётчик нажатий
- `FLastLine: TLastLineInfo` - информация о последнем слове:
  - `Text` - текст слова
  - `StartTick` - время набора
  - `BufferCopy` - копия буфера клавишных событий

### Обработчики
- `HandleRightCtrlPress` - обрабатывает нажатие правого Ctrl (вызывается из `HandleKeyUp`)
- `ToggleLastWord` - переключает последнее слово
- `ToggleLastLine` - переключает раскладку для строки

### Логирование
Все действия правого Ctrl записываются в `debug.log`:
- "Right Ctrl: одиночное нажатие - переключение последнего слова"
- "Right Ctrl: двойное нажатие - переключение раскладки"
- "ToggleLastWord: \"старое\" -> \"новое\""
- "ToggleLastLine: переключаем с русской на английскую"

## Использование

1. Напечатайте слово в неправильной раскладке (например, "ghbdtn" вместо "привет")
2. Нажмите **Правый Ctrl** один раз → слово переключится на альтернативную раскладку
3. Для переключения всей раскладки окна быстро нажмите **Правый Ctrl дважды**

## Примечания

- Буфер последнего слова сохраняется при достижении границы слова (пробел, знак препинания, Enter)
- Если буфер пуст или содержит менее 2 символов, переключение слова не выполняется
- Двойное нажатие работает только если интервал между нажатиями ≤ 300 мс
